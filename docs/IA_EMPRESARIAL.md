# Central de IAs para Conversas Empresariais

Uma seleção de 15 ferramentas de IA, sem repetição, organizada por ramo de trabalho. A proposta é usar esta página como um hub: cada categoria leva diretamente à ferramenta mais adequada para aquela finalidade.

> **Observação:** disponibilidade de planos gratuitos, limites de uso e recursos podem mudar. Os links abaixo apontam para os sites oficiais.

Para estruturar problemas, analisar cenários, tomar decisões, criar estratégias e trabalhar com documentos.

**Abrir:** https://chatgpt.com/

## Como usar em uma conversa empresarial

1. Identifique o objetivo da tarefa.
2. Escolha a categoria correspondente.
3. Abra a IA pelo botão/link.
4. Faça o trabalho na ferramenta escolhida.
5. Volte ao projeto para registrar o resultado, decisão ou material produzido.

### Regra do hub
**Uma categoria → uma ferramenta principal → nenhuma repetição.**

Esta estrutura pode ser expandida posteriormente com filtros por **Estratégia, Marketing, Vendas, RH, Finanças, Jurídico, Operações, Pesquisa e Comunicação Executiva**.
